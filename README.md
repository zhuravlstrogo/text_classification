# text_classification

Классификация текстов (тематика/тональность) с помощью fasttext.

## Структура

- `src/text_classification/` — основной код 
- `scripts/` — исполняемые скрипты
- `notebooks/` — Jupyter-ноутбуки
- `configs/`, `config/` — конфигурации
- `data/`, `models/`, `output/`, `reports/`, `logs/` — артефакты 
- `tests/` — тесты
